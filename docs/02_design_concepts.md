# 02. 디자인 컨셉 6종

첨부 이미지(RADIANT ME 시리즈 + 매거진형) 기준으로 매핑한 6종 컨셉. 각 컨셉은
**레이아웃 구조 + 컬러 팔레트**를 최대한 그대로 재현하고, 콘텐츠만 유저 데이터로 치환한다.

---

## 컨셉 1. Cream Elegant (아이보리 우아함)
- **참조**: 첨부 이미지 "01" (베이지 배경, 인물 우측 텍스트 배치형)
- **팔레트**: 아이보리/크림 베이스(#F7F3EC 톤), 브라운 텍스트(#5A4A3A 톤), 포인트 골드/베이지 카드
- **레이아웃**: 좌측 인물 사진 세로 배치 + 우측 섹션 카드 그리드. 섹션 카드는 둥근 모서리의 아이보리 박스, 은은한 그림자
- **타이포**: 세리프 계열 로고 타이틀("RADIANT ME"), 본문은 고딕
- **톤앤매너**: 차분하고 정갈한 라이프스타일 매거진 느낌

## 컨셉 2. Dark Forest Luxury (다크그린 럭셔리)
- **참조**: 첨부 이미지 "03" (다크그린/블랙 배경형)
- **팔레트**: 딥 포레스트 그린 ~ 블랙 그라데이션 배경, 화이트/골드 텍스트, 스카이블루 사진(스위스 산 이미지) 포인트
- **레이아웃**: 상단 넘버 배지 + 인물 사진 좌측, 텍스트는 얇은 세리프 이탤릭("Love myself. Live my life.")
- **타이포**: 이탤릭 세리프 슬로건 + 얇은 산세리프 본문
- **톤앤매너**: 고급스럽고 무게감 있는 에디토리얼 톤

## 컨셉 3. Lavender Soft (라벤더 파스텔)
- **참조**: 첨부 이미지 "04" (연보라/라벤더 배경, 꽃 일러스트 프레임)
- **팔레트**: 라벤더/연보라 그라데이션(#E8DFF0 톤), 화이트 카드, 보라 꽃 장식 요소
- **레이아웃**: 인물 사진 우측 하단 배치 + 꽃 일러스트가 프레임처럼 감싸는 구조, 섹션은 상단 정렬 그리드
- **타이포**: 부드러운 산세리프, 손글씨풍 슬로건 텍스트
- **톤앤매너**: 부드럽고 여성스러운 감성, 파스텔톤 힐링 무드

## 컨셉 4. Kraft Paper Vintage (크래프트 페이퍼 빈티지)
- **참조**: 첨부 이미지 "08" (크래프트 종이 질감, 폴라로이드 사진 배치)
- **팔레트**: 크래프트 브라운 종이 배경(#D9CBB4 톤), 화이트 폴라로이드 프레임, 손글씨 라벨
- **레이아웃**: 폴라로이드 사진들이 살짝 기울어진 채로 종이 위에 붙여진 무드보드 형태, 클립/테이프 장식 요소
- **타이포**: 손글씨체 캡션("나는 나의 속도로...") + 타자기 느낌 라벨
- **톤앤매너**: 아날로그 다이어리/스크랩북 감성

## 컨셉 5. Ocean Magazine Editorial (오션 매거진 커버형)
- **참조**: 첨부 이미지 "04 매거진 커버 & 갤러리" (블루톤 매거진 커버)
- **팔레트**: 오션 블루 ~ 화이트, 인물 사진이 배경 전체를 채우는 풀블리드 커버 스타일
- **레이아웃**: 상단은 매거진 커버형 풀스크린 인물샷 + 슬로건, 하단은 화이트 배경 위 섹션 카드(ABOUT ME, MY TASTE 등 매거진 목차 스타일)
- **타이포**: 볼드 매거진 타이틀("RADIANT ME") + 캡션 인용구
- **톤앤매너**: 세련된 라이프스타일 매거진 표지 느낌

## 컨셉 6. Pastel Dashboard (파스텔 대시보드형)
- **참조**: 첨부 이미지 "07" (연핑크/크림 배경, 아이콘 대시보드형)
- **팔레트**: 소프트 핑크/크림 배경, 화이트 카드, 파스텔 아이콘 컬러(청록/코랄/블루 포인트)
- **레이아웃**: 인물 사진 좌측 세로 배치 + 우측은 아이콘 기반 정보 위젯 그리드(취향/버킷리스트/사진 그리드가 각각 독립 카드)
- **타이포**: 라운드 산세리프, 아이콘 중심 정보 전달
- **톤앤매너**: 밝고 친근한 대시보드/플래너 느낌

---

## 공통 구현 규칙
- 6종 모두 **모바일 세로 1페이지 스크롤**로 재구성 (원본은 웹 포트폴리오형 그리드이므로 모바일에서는
  섹션을 세로로 스택하되, 각 컨셉 고유의 카드 모양/장식 요소/색감은 유지)
- 폴라로이드 기울임, 종이 질감, 그라데이션 배경 등은 CSS(box-shadow, transform: rotate, linear-gradient)로 최대한 구현
- 텍스처 이미지가 꼭 필요한 경우(크래프트 종이 질감 등)만 정적 배경 이미지 asset 사용, 나머지는 순수 CSS
- 컨셉 선택 시 미리보기 썸네일 6장을 제작 플로우에 제공 (이 문서의 참조 이미지를 축소 썸네일로 활용)
