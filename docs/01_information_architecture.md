# 01. 정보 구조 (Information Architecture)

## A. 메인 허브 화면 (`/`)

### 상단 헤더
- 텍스트: "조천리 부녀회 Heroes" (영문 그대로 표기, 로고 타이포처럼)
- 배경: 심플, 로고/타이틀 중심 (특정 컨셉 색에 종속되지 않는 중립 톤)

### 본문: 히어로 카드 캐러셀
- **세로형 카드**, 좌우 스와이프(모바일 네이티브 스와이프 제스처 + 스냅 스크롤)
- 카드 구성:
  - 이미지 영역 80%+ (인물 대표 사진, 참조: 첨부 7번 이미지의 카드 스와이프 UX)
  - 하단 20% 내외: 이름/닉네임 + 요약 1~2문장 (해당 유저가 입력한 소개 문구 중 발췌 또는 별도 "한줄소개" 필드)
  - **불필요한 잡정보 제거**: 별점, 영업시간, 카테고리 뱃지 등 커머스성 UI 요소는 사용하지 않음
  - 카드 자체를 기존 샘플보다 세로로 더 길게 (화면 세로의 70~80% 차지)
- 카드 클릭/탭 → 해당 유저의 개별 홈피 페이지로 라우팅 (`/h/[userSlug]`)
- 카드 정렬 순서: 관리자 모드에서 수동 정렬 가능 (기본은 등록순 또는 추천순)
- 하단 인디케이터(점 또는 진행 바)로 현재 위치 표시 (7번 이미지 참고)

## B. 개별 홈피 화면 (`/h/[userSlug]`)

모바일 전용 1페이지 스크롤형. 진입 시 mp3 자동재생 시도 (04번 문서 로직 참조).

### 공통 섹션 구조 (RADIANT ME 시리즈 기준)
1. **프로필 헤더**
   - 프로필 사진 (인물 컷)
   - 이름/타이틀
   - 한 줄 슬로건 (예: "나는 나의 속도로 아름답게 피어나고 있습니다")
2. **01 나의 취향**
   - 아이콘 + 라벨 형태의 태그 그리드 (음식/영화/책/취미/MBTI 등, 유저가 자유 추가/삭제 가능한 리스트)
3. **02 나의 꿈과 도전**
   - 버킷리스트 TOP 3 (아이콘 + 순위 + 텍스트)
   - "가고 싶은 여행지" / "배워보고 싶은 것" 카드 2개 (이미지 + 텍스트)
4. **03 나의 강점**
   - 이미지 2장 + 짧은 설명 텍스트
5. **04 내가 사랑하는 것**
   - 이미지 카드형, 자유 텍스트 라벨
6. **05 나를 행복하게 하는 순간**
   - 사진 갤러리형 그리드 (2~4장)
7. **하단 클로징 문구**
   - 캐치프레이즈 텍스트 (예: "오늘의 나를 응원해요")
   - "LOVE MYSELF · LIVE MY LIFE" 류의 서브 태그라인 (컨셉별 문구는 다를 수 있음, 유저 커스텀 가능)

### 네비게이션
- 개별 홈피 좌측 상단 또는 하단에 "← 허브로 돌아가기" 버튼 고정 노출
- 뒤로가기 시 캐러셀 스크롤 위치 유지 (메인 허브 상태 보존)

## C. 유저 제작 플로우 (`/create`)
1. 로그인 (Google Auth)
2. 디자인 컨셉 6종 중 1개 선택 (썸네일 미리보기 카드로 제시)
3. 섹션별 텍스트 입력 (01~05 섹션에 대응하는 폼)
4. 참조 이미지 업로드 (프로필 1장 + 섹션별 이미지 슬롯)
5. mp3 업로드
6. 실시간 미리보기 (선택한 컨셉 스타일 적용된 상태로 확인)
7. 게시 → 관리자 승인 대기 (관리자 모드 On 시) 또는 즉시 게시
